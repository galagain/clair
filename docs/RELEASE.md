Clair 0.29.0 corrige les appels IA cachés et les écritures de cache inutiles.

- Désactiver Pistes sur le Mac annule ses analyses en cours et en attente ; la transcription et la traduction restent indépendantes.
- Les traductions envoient uniquement la prise de parole ; tous les appels Responses désactivent le cache de prompts. Les frais d’entrée, de sortie et de transcription restent applicables.
- F2 coupe les Pistes et la traduction ; les relancer reste un choix explicite.
- Les boutons et raccourcis associés dans Clair communiquent directement avec l’extension Firefox, sans simuler de frappes qui pourraient écrire dans l’éditeur.

Rechargez l’extension Firefox et reconnectez-la après mise à jour. Ouvrez-la sur l’onglet d’exercice pendant la préparation pour lui accorder l’accès à cet onglet.

Versions Mac Apple Silicon et Windows x64 non certifiées. Tests avec API simulée ; pertinence et coût d’une session API réelle à confirmer.
