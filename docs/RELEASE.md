Clair 0.29.3 remet la recopie à portée de clic.

- Bouton Recopie à côté du dossier, en haut : un clic lance, un second arrête.
- Utilise les derniers écrans et la qualité choisis ; ouvre les réglages si deux écrans ne sont pas disponibles.
- La configuration reste regroupée dans Réglages → Recopie d’écran.

Contrôles Electron avec écrans et module simulés, sans capture réelle ni appel API. Versions Mac Apple Silicon et Windows x64 non certifiées ; recopie disponible sur Mac.
