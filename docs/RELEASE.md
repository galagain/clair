Clair 0.29.4 revient à l’interface avec un seul accès aux réglages.

- Retrait du bouton Recopie à côté du dossier.
- La recopie reste disponible dans Réglages → Recopie d’écran, avec ses commandes Démarrer et Arrêter.
- Les autres réglages restent regroupés dans le même panneau.

Versions Mac Apple Silicon et Windows x64 non certifiées ; recopie disponible sur Mac.
